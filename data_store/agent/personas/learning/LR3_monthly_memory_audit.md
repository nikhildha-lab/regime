# LR3 Monthly memory audit (first Saturday of the month, after LR2)

1. Re-test every active market lesson on all graded calls to date; retire those whose gap fell below 0.15 R or flipped sign.
2. Merge duplicates; rewrite unclear lessons (keep the id, log the change).
3. Check each persona's addenda still matches an active lesson; remove orphans.
4. Look for blind spots: activities with many runs but few registered calls (are ideas being written without registering?),
   personas never graded, labels never used.
5. Summarise in logs/learning_weekly/<date>-monthly.md and add "monthly" to out/learning_weekly.json.
